# Хвост под контролем

Публичная рекламная страница и страница проверки версий Android-приложения.

- `/` — описание и скачивание APK.
- `/testing/` — изменения, видео с женской синтезированной озвучкой, отдельное аудио, сохраняемый чек-лист. Раздел доступен по ссылке и не защищён паролем; личные данные здесь не публикуются.
- `release.json` — сведения о текущем файле и SHA-256.
- APK собирается из частей при публикации и скачивается напрямую с GitHub Pages; исходников Android и ключей подписи в этом репозитории нет.

## Публикация

GitHub Pages публикуется существующим workflow репозитория `nicolenkoe/enduro-club-downloads`. Его build.py копирует каталог `hvost-pod-kontrolem` в одноимённый подкаталог `_site`. Существующие страницы и APK Enduro не заменяются. Сам сайт статический, без сборщика и внешних зависимостей.

## Обновление релиза

1. Проверить и подписать APK прежним сертификатом.
2. Добавить проверенный APK частями в hvost-apk-parts и обновить сборку в build.py.
3. Обновить ссылки, номер, размер, SHA-256 в index.html, testing/index.html и release.json.
4. Добавить изменения и пронумерованные проверки; сохранить предыдущие инструкции в истории.
5. Разместить актуальные MP4 с русской женской озвучкой и MP3 в assets; обновить подписи VTT. Использовать только демонстрационные материалы, не файлы пользователей.
6. Проверить относительные ссылки, JavaScript, скачивание APK и целостность файла, затем опубликовать main.
7. Отправить владельцу ссылки на сайт, APK и инструкцию по согласованному каналу.

Сайт не подключает аналитику. Отметки чек-листа остаются в браузере посетителя.
