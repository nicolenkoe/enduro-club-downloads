# Enduro Club — скачивание игры

Официальная страница скачивания Enduro Club Ленинградская.

Версия Android: **0.15.68**.

В этом репозитории размещаются только файлы для распространения игры:
страница, готовый APK (в частях для хранения Git), инструкция и видео с озвучкой.
Исходники игры, закрытый генератор активации, пароли и ключи сюда не входят.

## Публикация

Settings → Pages → Build and deployment → Source → **GitHub Actions**.
Workflow **Publish APK download page** собирает APK, проверяет размер и SHA-256,
публикует страницу и затем скачивает APK целиком для сравнения.

После успешной публикации адрес страницы:
https://nicolenkoe.github.io/enduro-club-downloads/

Наличие файлов в репозитории само по себе не означает, что Pages уже работает.
